# O Teste da Letra Pequena

Freebie da Sandra Monteiro Seguros. Quiz de 5 perguntas → 1 de 4 perfis.

## Como correr localmente

Abre o ficheiro `index.html` num browser (duplo clique, ou arrasta para uma janela do Chrome/Edge).

## Próximo passo

Liga o botão final ("Marcar os meus 20 minutos") ao teu evento — masterclass, imersão ou call de diagnóstico. Substitui `[LINK_A_DEFINIR]` dentro do `index.html` pelo link real.

Publicar isto online, com domínio próprio para o link da bio, é um passo técnico à parte. Por agora, esta pasta é tudo o que precisas.
